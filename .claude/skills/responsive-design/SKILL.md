# Responsive Design

## Goal

Create layouts that adapt naturally rather than simply shrinking desktop layouts.

## Target environments

The application should work well on:

- Mobile phones
- Tablets
- iPads
- Laptops
- Desktop monitors

## Principles

- Design mobile intentionally.
- Do not rely on fixed widths.
- Avoid horizontal scrolling unless explicitly required.
- Use responsive spacing.
- Use responsive typography where appropriate.
- Ensure buttons and inputs have comfortable touch targets.
- Keep important actions reachable on mobile.
- Preserve visual hierarchy at every viewport size.

## Testing

Check at minimum:

- Small mobile
- Large mobile
- Tablet
- iPad
- Laptop
- Desktop

## Important

Do not simply hide content to make a layout fit.

Reorganize the layout when necessary.

For the authentication flow, mobile usability is especially important because restaurant managers may log in and create reservations from their phones.
