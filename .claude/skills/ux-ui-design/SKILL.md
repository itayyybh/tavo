# UX/UI Design

## Goal

Design interfaces that make the user's next action obvious and minimize unnecessary cognitive load.

## Before implementation

Think through:

1. Who is using this screen?
2. What is the primary goal?
3. What is the most important action?
4. What information does the user need?
5. What can be removed?
6. What happens after each action?
7. What happens when something goes wrong?

## Principles

- Make primary actions obvious.
- Keep secondary actions visually secondary.
- Minimize unnecessary steps.
- Avoid unnecessary modals.
- Use clear labels.
- Provide immediate feedback.
- Keep related information grouped.
- Maintain predictable navigation.
- Prefer familiar interaction patterns.

## Login-specific UX

Consider:

- Returning users
- New users
- Incorrect credentials
- Forgot password
- Loading
- Session expiration
- Network failures
- Successful authentication

The user should never be unsure whether an action succeeded.

## Important

Do not redesign functionality merely for the sake of redesigning it.

Preserve existing business logic unless the current UX genuinely prevents good usability.
