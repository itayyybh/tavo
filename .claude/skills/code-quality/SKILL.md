name: code-quality
description: Code quality standards for every file in this project — typed, reusable, documented, clean, no duplicated logic, prefer utilities, avoid nested logic. Use when writing, refactoring, or reviewing any code.
---

Every file / component must be:

- typed
- reusable
- documented
- clean

Rules:

- No duplicated code — extract utilities.
- Prefer utility functions.
- Avoid deeply nested logic.
- No large files.
- Maximum readability.
