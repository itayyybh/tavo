Use when working on the layout / floor-plan / restaurant-builder editor.
---

The layout editor behaves like Figma.

Requirements:

- Grid
- Snap to grid
- Drag
- Selection
- Multi selection
- Zoom
- Pan
- Rotation
- Resize (where applicable)
- Keyboard shortcuts
- Undo
- Redo

Rules:

- Never build fixed positioning.
- Everything must be object-based and stored as objects.
